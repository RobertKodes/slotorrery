# slotorrery

Live Solana mainnet as a **brass museum orrery**.

The slot clock is the sun. Hot program families are planets — orbital speed ≈ activity. Recent txs streak as comets. Fee pressure warps the gravity well. Failed txs burn out red.

Not an explorer. Not a dashboard. Not a newspaper.

Target live: https://robertkodes.github.io/slotorrery/
